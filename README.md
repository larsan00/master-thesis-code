# master-thesis-code
Python source code used for the numerical simulations, data analysis, and figure generation presented in my Master's thesis. 

The code is organized into three dedicated branches:

Check – testing and validation of the numerical implementation and physical test scenarios (Chapter 3).
Asymmetry – asymmetry analysis based on a point-force setup and comparison with analytical solutions (Section 4.1).
Breathing-Efficiency – investigation of human breathing efficiency under different physical conditions (Section 4.2).

Please refer to the corresponding branch for the simulation and plotting scripts associated with each study.
